AtmoSync: Micro-Climate Arbitrage Analytics

Project Overview

AtmoSync analyzes historical weather data from popular cities in Maharashtra.

Week 1

- Collected weather datasets for different cities.
- Explored available datasets.

Week 2

- Completed data cleaning and preprocessing.
- Performed Exploratory Data Analysis (EDA).
- Analyzed weather patterns and identified useful insights.

Objective

To understand weather variations across different cities using data analytics.
